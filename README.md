# Chroma

A free perfect pitch trainer. Every note gets one fixed color (laid out on the circle of fifths), a name and an octave, and you learn to hear it, name it and sing it.

- **Train:** ten-minute sessions that mix a spotlight warm-up, blind naming blocks with an answer key, singing notes back from memory, and recall.
- **Quick note:** one cold note between lessons, scored as a first note.
- **Learn:** explore the keyboard and color wheel, spotlight notes, and hold a pitch against a live tuner.
- **Progress:** first-note, comeback, singing and per-note scores.

Runs in the browser. Singing uses the microphone, and all audio is processed on your device.
